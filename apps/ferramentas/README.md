# Ferramentas gratuitas da Dupply

Servidas em https://ferramentas.dupply.com.br/<ferramenta>

- /assinaturas — calculadora de assinaturas (porta de entrada para o Otto)

Cada ferramenta nova é uma pasta com um index.html. Deploy: app no Coolify
apontando para este repositório, Base Directory `/apps/ferramentas`,
build pack Dockerfile, porta 80, Watch Paths `apps/ferramentas/**`.
